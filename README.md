# 🦷 Landing Page - Dra. Maria Silva (Odontologia)

Uma landing page moderna, responsiva e de alta conversão desenvolvida especificamente para profissionais de odontologia. O projeto foca em apresentar tratamentos, autoridade profissional e facilitar o agendamento de consultas.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias web puras para garantir máxima performance, SEO e facilidade de manutenção:

*   **HTML5:** Estrutura semântica para melhor acessibilidade e indexação nos motores de busca.
*   **CSS3:** Estilização personalizada utilizando variáveis CSS, Grid e Flexbox para um layout moderno e responsivo.
*   **JavaScript (Vanilla):** Lógica simples e eficiente para interações e validações.
*   **Google Fonts:** Tipografia premium (Fonte 'Outfit') para um visual elegante.

---

## ✨ Funcionalidades

*   ✅ **Design Responsivo:** Adaptado para celulares, tablets e desktops.
*   ✅ **Seção Hero de Alto Impacto:** Chamada para ação (CTA) clara e direta.
*   ✅ **Sobre Mim:** Espaço para destacar a trajetória e especialidades da profissional.
*   ✅ **Grade de Tratamentos:** Apresentação visual das especialidades (Ortodontia, Estética, Implantes, etc).
*   ✅ **Seção de Benefícios:** Destaques sobre o diferencial do atendimento.
*   ✅ **Formulário de Contato:** Integrado e pronto para facilitar a comunicação do paciente.
*   ✅ **SEO Otimizado:** Metadados configurados para melhor visibilidade no Google.

## 🛠️ Como Executar o Projeto Localmente

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/Edson-Alves-Git/landingpage-dentista.git
    ```

2.  **Acesse a pasta do projeto:**
    ```bash
    cd landingpage-dentista
    ```

3.  **Abra o arquivo `index.html`** diretamente no seu navegador ou utilize um servidor local:
    *   Com **VS Code**: Use a extensão "Live Server".
    *   Com **Node.js** (instalado):
        ```bash
        npm install
        npm run dev
        ```
